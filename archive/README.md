# Archive – earlier exploratory runs (superseded)

`earlier_claude_runs_FYP_model_results.zip` contains the earlier development runs: the `simple`, `grouped`
and `strict` versions, with test F1 between 0.7265 and 0.8067. They used different splits, grouping keys
and preprocessing, and one version had a grouping bug that was later fixed.

They are kept for transparency only:
- **The dashboard does not use them**, and their numbers must not be mixed with the main results.
- They are the reason the thesis must disclose **test-set exposure**: their test scores were seen
  before the final controlled experiment was designed.
- The same ZIP is also preserved, with an independent audit, in `experiment/audit/`.
